# GUI 手工回归矩阵

**简体中文** | [English](MANUAL-REGRESSION.en.md)

自动化测试不能改变物理显示器拓扑。发布前至少覆盖下表，并保存版本、Windows
构建号、显卡、缩放比例和结果。

每次 CI 会执行短时完整 UI 场景压力测试；每周工作流执行 30 分钟版本，反复
覆盖圆角按钮绘制、输入框注册、日志滚动区、带图标列表和三级窗口层级。下表
只记录自动化无法代替的物理显示器与人工观感证据。

2026-07-29 已在 Windows 11 实机 200% DPI 下跑通完整 GUI 自动化套件；这不是人工
视觉验收，因此上表各格仍保留“待验证”。可复现的设备、主题、资源循环和辅助功能
证据见[GUI 验证记录](VALIDATION-EVIDENCE.md)。

还应检查：

- 浅色、深色与 Windows 高对比度模式。
- 仅键盘完成添加、设置保存、日志选择和关闭窗口。
- 触控板滚动、滚轮滚动和滚动条拖拽保持原生行为且没有白色闪烁。
- 主界面和应用搜索的每个伪表头均按升序、降序、自定义／来源顺序循环，第四次点击重新升序。
- 文本输入区显示文本光标，日志和滚动条保持普通光标。
- 屏幕阅读器能够读出关键按钮名称、设置标签和状态文本。
