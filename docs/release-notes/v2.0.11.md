# 🎉 进程守护小助手 v2.0.11

## ✨ 新增

- **版本目录升级迁移**：对安装在 `2.0.10`、`v2.0.11` 等版本目录中的直接文件目标，升级保护确认文件变化后会在同一父目录寻找唯一的同名新入口，记录并持续校验候选 SHA-256，再交由用户确认是否更新守护路径；多候选、重复副本或扫描不完整时不会猜测。

---

## 🚀 优化

- **升级保护识别更完整**：文件监听溢出、子目录同名文件和升级会话中的配置、资源、压缩包等变化会触发及时复核；已确认目标足迹变化后，也能识别由系统安装服务代理且缺少安装路径参数的近期安装进程，同时避免把共享安装目录中的日常写入误当成升级。
- **更新程序学习可解释且可恢复**：真实升级中确认的专属更新程序会按“完整路径 + 安装根”学习；全局安装工具、临时目录程序和只有进程名的记录不会成为永久证据。未完成会话会保存瞬时更新进程及待学习特征，重启小助手后仍可继续判断，并在升级成功完成时写入学习记录。
- **进程识别兼容受限路径**：完整镜像路径查询失败时增加设备路径回退；仅在已确认升级且存在唯一同名进程时，才结合升级前 PID 创建身份或近期启动时间确认目标已经恢复，减少软件实际运行却一直等待到升级超时的情况。
- **维护扫描与诊断更清晰**：多目标升级扫描复用公共候选和已解析的命令行路径，只对已确认发生升级足迹变化的目标检查完整进程快照；诊断包新增工作互斥的占用者、等待和持续时间，以及后台进程快照和文件扫描的失败类型、重试与最近成功信息。
- **发布字体恢复不再依赖 LFS 配额**：需要完整字体的 CI、长测、发布演练和正式发布改从最新正式 `fonts.zip` 恢复资产，并按当前字体清单逐项核对 SHA-256；Git 仓库仍以 LFS 跟踪超大字体，但远端 LFS 配额不足不再阻断已验证字体的测试和打包。
- **升级保护设置更易读**：三个时间字段取消冒号并与输入框左对齐，安装目录操作按钮保留完整文字，清除记录与下方文本框的间距也更紧凑。

---

## 🐛 修复

- **升级后运行状态不再误判超时**：修复部分软件升级后已经启动，但进程镜像路径暂时不可访问，导致小助手持续显示升级等待并最终超时的问题；同名候选不唯一或创建身份无法核实时仍保持未知，不会盲目认领。
- **后台任务失败原因不再丢失**：进程快照和内容扫描现在区分启动失败、无结果退出、超时、结果格式错误与取消；修复文件扫描工作进程结束后，格式错误结果被继续当作“尚未完成”的状态。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.0.11-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.0.11-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
