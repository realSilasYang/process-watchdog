# 🎉 进程守护小助手 v2.0.5

## ✨ 新增

- **按内容找回移动目标**：直接添加的程序或脚本会保存文件大小与 SHA-256 内容基线。文件本身或上级目录改名、跨目录或跨磁盘移动后，即使移动发生在小助手关闭期间，也可在确认内容完全一致后更新守护路径；文件名、文件 ID 和目录监听不作为身份依据。
- **原生路径编辑深色主题**：主列表的完整路径原位编辑框现在使用当前输入框背景与文字颜色，右键、双击和 F2 三种入口保持一致。

---

## 🚀 优化

- **高效且保守的迁移扫描**：优先递归检查旧路径最近仍存在的目录，扩大范围后使用 Everything 按扩展名和精确大小缩小候选，再在独立工作进程中计算完整哈希；多个相同副本或未完成扫描不会触发猜测迁移。
- **批量路径编辑**：多选后逐项编辑完整路径时，按 Enter 保存当前条目并自动进入下一项；Esc 仍只取消当前编辑。
- **真正结束目标运行**：右键菜单以“结束运行”取代“重新启动”，先暂停该守护对象再按停止策略关闭目标，避免守护立即重新拉起进程。
- **系统入口与反馈**：创建快捷方式会分别写入并读回验证桌面入口和开始菜单“所有应用”入口，再同步通知 Windows Shell；成功时隐藏创建按钮并完整显示反馈文字，错误弹窗的图标、正文和按钮统一居中布局。
- **首帧深色绘制**：主窗口首次可见前在 DWM 遮蔽期间完成标题栏、列表、表头、状态栏和命令按钮的深色绘制，减少深色模式启动时的白色闪帧。
- **公开发行物终验**：正式发布在核对本地构建与 GitHub 元数据并公开后，会重新下载实际托管的独立 EXE、便携 ZIP 和源码 ZIP，再次核对摘要、解压并复用完整发行包校验；发布专用动态工具链快照与普通 CI 固定快照严格分离，避免审计基准混用。

---

## 🐛 修复

- **守护状态收敛**：修复内容迁移回调参数不匹配导致主监控在进程观测前异常、多个实际运行目标长期停在“初始化”，以及缺失目标在“等待进程状态”和“不存在”之间反复切换的问题。
- **主窗口首次显示**：修复顶部除“添加”外的命令按钮偶发需悬停或点击后才绘制，以及底部状态栏首次打开延迟显示的问题。
- **路径编辑入口一致性**：修复 F2 继续交给 ListView 默认处理并创建第二个亮色编辑框的问题；主题热切换也会刷新当前原位编辑框。
- **重载与快捷方式错误**：重载交接改用显式窗口句柄并逐步容错，避免旧窗口恰好退出时出现“Target window not found”；快捷方式创建失败现在报告实际未完成的入口。

## 📦 发布物说明

- **`process-watchdog-2.0.5-windows-x64.exe`（独立可执行版）**：无需安装 AutoHotkey，下载后即可运行，适合快速体验或只需要单个程序文件的用户。
- **`process-watchdog-2.0.5-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证、字体及运行所需资源，适合完整解压后长期使用或手动部署。
- **`process-watchdog-2.0.5-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试、文档和字体资源，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
