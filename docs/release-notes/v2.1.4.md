# 🎉 进程守护小助手 v2.1.4

## 🚀 优化

- **恢复确认措辞**：界面与文档中的“停止后每次询问恢复”统一改为“每次恢复前询问”，更准确地描述确认发生的时机。

## 🐛 修复

- **批量启动与恢复隔离**：首次批量启动或批量恢复守护对象时，单个脚本或软件启动异常只记录该对象并安排自身重试，不会中断其他守护项的启动和恢复。
- **完全批量结束运行**：多选或全选后结束运行时，所有守护对象继续完全并发处理并各自隔离异常；提高 AutoHotkey 线程容量后，大批量操作不再因默认线程上限使列表尾部条目长时间停留在“正在结束运行”。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.1.4-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.1.4-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
