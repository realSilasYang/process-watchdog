# 🎉 进程守护小助手 v2.0.13

## 🚀 优化

- **快捷方式创建更可靠**：桌面与开始菜单入口现在成对创建并校验，任一入口失败时恢复原状态，避免留下半完成快捷方式；成功入口会及时通知 Windows Shell 刷新。

---

## 🐛 修复

- **普通 AHK 脚本图标不再被污染**：源码版小助手使用独立稳定的 Windows 应用身份，开始菜单与桌面快捷方式直接指向小助手脚本并保留专属 Logo，不再把产品图标关联到共享 AutoHotkey 解释器；既有旧格式入口会在严格确认属于本项目后自动迁移。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.0.13-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.0.13-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
