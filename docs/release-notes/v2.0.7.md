# 🎉 进程守护小助手 v2.0.7

## 🚀 优化

- **进程识别诊断更可解释**：守护对象因现有进程无法可靠核对而延迟启动时，日志会说明观测来源、原因和原因码，并对重复原因做节流，帮助判断是命令行、进程路径、快照还是探活配置导致的不确定。
- **内容迁移过程更透明**：按内容找回移动目标时，会记录缺失稳定等待、搜索根、扫描方式、扫描失败/超时、候选被拒绝、重复副本和未命中等关键阶段，避免用户只能看到“没有迁移”的黑箱结果。
- **Everything 依赖体验更清楚**：程序搜索会区分随包 `Everything64.dll` 与 Everything 本体，后台实例未响应时先尝试定位并启动 Everything；失败时显示具体错误含义、发现过程或官方下载入口。
- **主界面展示更易读**：状态信息列默认宽度从 180 调整为 200，README 界面概览同步替换为当前主窗口截图。
- **发布工程输出更干净**：可复现构建默认写入受控临时目录并自动清理，CI、演练和正式发布工作流显式指定 `dist` 输出，避免本地发布预检遗留构建产物。

---

## 🐛 修复

- **Everything 失败提示稳定性**：修复 Everything 不可用诊断文本拼接在 AutoHotkey 中可能触发三元表达式解析错误的问题。
- **关于页信息列布局**：版本与运行环境信息列现在按关于页分隔线边界计算，不再越过分隔线或被设置表单的右侧余量影响。
- **打开所在位置的文件管理器选择**：系统默认文件管理器是 Explorer 时继续选中文件；否则改为交给默认文件管理器打开所在目录。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.0.7-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.0.7-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
