# 🎉 进程守护小助手 v2.1.0

## ✨ 新增

- **小助手管理员运行可配置**：启动页新增“以管理员身份运行”；默认保持开启，关闭后小助手使用当前用户权限运行，重新开启时通过安全交接请求 UAC，并让已存在或新建的计划任务同步采用相同权限级别。
- **守护序号支持批量彩点**：主列表右键浮层新增七种深浅主题配色和清除入口；右键已选条目会保留多选，可一次为多个守护对象设置序号圆点，颜色只影响显示，不参与进程识别、启动或升级保护。
- **主列表动态惯性滚动**：滚轮输入按速度动态加速和减速，连续滚动更平滑；拖拽排序、窗口销毁和边界到达时会及时停止并恢复系统计时精度。

---

## 🚀 优化

- **右键菜单更紧凑稳定**：普通命令恢复本地化 Emoji 文本并取消分隔线，“设置序号圆点”单独使用放大的主题色调色盘图标；浮层继续保持不激活、圆角悬停和靠右勾选布局。
- **主列表多选交互更自然**：右键已选条目不再折叠现有多选，右键未选条目才切换为单选；选中项不再显示原生焦点边框，序号彩点由子项绘制管线稳定渲染。
- **发行包本地状态隔离加强**：便携包和源码包会递归拒绝 `watchdog.ini`、`watchdog.maintenance.ini`，并验证示例配置的守护、升级、显示、启动、身份和恢复分区均没有本机记录。

---

## 🐛 修复

- **窗口唤起后按钮立即可见**：任务栏还原、其它实例唤起或子窗口再次显示后会刷新圆角按钮，无需再把鼠标逐个移过控件才能看到内容。
- **右键浮层关闭不再访问失效窗口**：关闭时快照并校验原生句柄，定时器和鼠标回调不会继续读取已经销毁的 GUI，避免重复弹出“Gui has no window”。
- **圆点清除标记居中**：清除按钮的叉号改为按控件几何中心绘制，不再受字体、语言或 DPI 基线影响。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.1.0-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.1.0-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
