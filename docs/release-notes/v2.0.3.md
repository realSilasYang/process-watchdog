# 🎉 进程守护小助手 v2.0.3

## ✨ 新增

- **目标更名与移动找回**：直接添加的程序或脚本在小助手运行期间更名、父目录更名或在同一卷内移动后，可在文件系统允许按 Windows 文件 ID 回开时找回新路径；该能力不可用时仅以完整的 Windows 重命名事件作为回退，不按相似名称猜测。
- **路径确认与撤销**：检测到候选后冻结该守护对象的重启流程，由本地化确认窗口展示原路径、新路径和识别依据；确认只更新守护路径并保留名称、图标、参数、环境、运行时和升级保护设置，且支持撤销与重做。

---

## 🚀 优化

- **主窗口命令按钮**：添加、暂停／恢复和删除按钮使用固定图标槽；暂停与恢复符号改用统一几何画布绘制，字符图标按实际栅格墨迹居中，状态切换、主题切换和高 DPI 重绘时不再发生图文跳动。
- **目标状态表达**：等待确认新路径拥有独立的状态图标和异常优先级，列表排序、状态栏和守护控制器能够区分目标缺失、等待确认与正常初始化。
- **README 品牌展示与界面概览**：十三种语言首页参照 CodeBookmark 加入统一居中的高清透明 Logo，并继续共用更新后的当前主窗口预览资源。
- **赞赏入口文案**：捐赠按钮使用更简短的悬浮提示，捐赠窗口与十三种语言 README 以直接的方式引导用户选择支持渠道。

---

## 🐛 修复

- **暂停后恢复更名目标**：修复目标在暂停期间更名后，恢复守护可能一直停留在“初始化”的问题；未启用升级保护时，残留目录活动信号不再阻止目标找回。
- **缺失目标识别时序**：目标文件已更名但旧进程仍在运行、进程快照暂不可用或单实例提示刚关闭时，先核对文件身份再判断是否重启，避免把路径变化误判为程序停止并重复启动。
- **路径迁移事务**：手工编辑与自动找回统一执行目标冲突、快捷方式和运行时配置校验；配置写入失败时回滚整个状态，避免列表、运行态和 INI 持久化结果不一致。

## 📦 发布物说明

- **`process-watchdog-2.0.3-windows-x64.exe`（独立可执行版）**：无需安装 AutoHotkey，下载后即可运行，适合快速体验或只需要单个程序文件的用户。
- **`process-watchdog-2.0.3-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证、字体及运行所需资源，适合完整解压后长期使用或手动部署。
- **`process-watchdog-2.0.3-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试、文档和字体资源，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
