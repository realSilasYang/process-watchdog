# 🎉 进程守护小助手 v2.0.0

## ⚠️ 重要说明

- `v1.0.0` 尚无自更新能力，升级到 `v2.0.0` 时必须手动下载并完整替换一次发行包；此后 EXE 版和源码版均可使用小助手内置更新。
- 程序搜索现在只使用正在运行的 Everything 服务，不再内置全盘扫描回退，也不限制应用层结果数量；文件夹批量导入不受影响。
- 通过 Git 获取源码时必须安装 Git LFS 并执行 `git lfs pull`；Release 附带的源码 ZIP 已包含完整字体资源，无需 Git LFS。
- 软件升级保护仍默认关闭，需按守护项手动启用并结合一次真实升级确认识别结果。

---

## ✨ 新增

- 为 EXE、Git 源码和普通源码加入完整的自更新流程，支持启动时后台检查和手动检查。更新前会校验版本、清单、SHA-256 与入口元数据，更新后等待新进程完成配置、窗口和核心守护初始化；失败时恢复程序及个人配置。
- 新增简体中文、港繁、台繁、英语、日语、越南语、韩语、西班牙语、法语、葡萄牙语、俄语、德语和意大利语本地化。界面默认跟随 Windows，也可在设置中即时切换语言和字体，无需重启守护运行时。
- 新增完整浅色主题与“跟随系统”主题选项；深浅色模式共同覆盖主窗口、各级窗口、菜单、提示、输入控件、选项卡、滚动条和禁用状态。
- 新增“帮助信息”窗口、反馈入口和捐赠窗口；运行日志与使用说明由同一入口选择打开。
- 主列表新增自动编号列和语义化彩色状态图标；BAT／CMD 项目可在右键菜单查看由小助手实际启动并捕获的独立标准输出及错误输出日志。

---

## 🚀 优化

- 重构核心守护调度、目标控制器、任务代际与变更队列，统一暂停、恢复、删除、排序、路径变更和撤销／重做的状态提交，减少整表重载、陈旧回调和重复检查。
- 加强 EXE、脚本、快捷方式及安装器间接入口的目标识别；综合进程快照、命令行、工作目录、父子关系、权限和文件证据，未知状态不再触发盲目重启。
- 重整设置页为“通用、监控与启动、停止策略、日志、关于”，并统一现代化标签、按钮、输入框、下拉框、间距和 DPI 布局；版本、运行环境、更新入口和项目地址集中到关于页。
- 主窗口、上下文菜单及各子窗口统一为无 Emoji 的语义化矢量图标和圆角交互；优化 ListView 列宽、图标缩放、选中状态、禁用反馈、窗口层级及拖动缩放后的重绘稳定性。
- 按语言重新选择界面内容字体。优先使用已安装字体，其次私有加载随包授权字体或 OFL 字体，最后回退至对应 Noto 字体；按钮、设置标签和状态栏独立使用系统 UI 粗体。
- `watchdog.ini` 的自动注释现跟随全部十三种界面语言生成；节名、键名和值保持兼容，切换语言或重复保存不会累积旧注释。
- 明确同目录 EXE 与源码共用配置、不同目录配置独立；快捷方式和计划任务只保留最后选择的日常入口，并可在两种运行形态间安全切换。
- 收敛仓库根目录，将项目治理、贡献、安全、支持、第三方声明、多语言文档、应用资源、配置示例和发行输出归入固定目录；README 新增概览图并重写安装、使用、诊断与贡献入口。
- 正式发布只允许从 `main` 手动触发，并在每次发布时重新解析 AutoHotkey 最新稳定版和 Ahk2Exe 最新发布版。新增只读发布演练、可测试的冲突状态机、三附件白名单、同提交中断恢复，以及草稿和公开版本的双重审计。
- 普通 CI 改用经哈希固定的仓库工具链快照和缓存；完整 `dist` 继续保存在 Actions 构建产物中，GitHub Release 只保留三个用户版本。

## 🐛 修复

- 修复短命重复启动进程、权限不足、瞬时检查失败或升级过程被误判为目标停止，导致单实例程序被错误重启、恢复死循环或升级保护长期等待的问题。
- 修复暂停项在重启后恢复时状态未初始化、手动排序未持久化、删除后撤销触发全部项目初始化，以及多选操作与陈旧异步回调覆盖新状态的问题。
- 修复子窗口最小化或关闭连带影响主窗口、底部状态栏及按钮在缩放后重绘不完整、浅色禁用色时序错误、选择背景丢失和输入焦点行为不一致的问题。
- 修复多尺寸程序图标缩放模糊、透明背景变黑、非方形图标偏移，以及 SVG 和常见图片格式自定义图标的加载与缓存问题。
- 修复自动更新对 Git worktree、重命名入口、清单粒度变化、陈旧检查结果、部分启动失败和配置回滚处理不完整的问题，并确保旧入口保留到同卷原子替换前的最后一步。
- 修复最新版 Ahk2Exe 不支持 `/setversion` 导致构建失败，以及更新校验清单解析、草稿续传退出码、英文批量导入标点和少量状态文本未本地化的问题。
- 修复 Release 错误附带独立 SBOM 与校验清单、重复 CI 和工具链漂移的问题；自动更新优先校验 GitHub Release API 提供的附件 SHA-256。

## ✅ 验证范围

- 自动门禁覆盖完整历史与敏感信息扫描、PowerShell 和 AHK 静态检查、核心测试、真实 GUI 冒烟与资源循环、两次可复现构建、发行目录结构、依赖许可证、字体来源、SBOM、校验清单和 GitHub 发布记录。
- 每次正式发布使用同一份动态解析的工具链快照完成全部测试与构建；三个公开附件上传到草稿后逐一比对本地哈希，公开后再核对远程标签和 Release。
- 本版未单独完成 Windows 10、高对比度模式及多显示器混合 DPI 的物理人工矩阵；自动化结果不替代这些环境的后续验证。

完整历史参见 [`CHANGELOG.md`](https://github.com/realSilasYang/process-watchdog/blob/main/CHANGELOG.md)。

## 📦 发布物说明

- **`process-watchdog-2.0.0-windows-x64.exe`（独立可执行版）**：无需安装 AutoHotkey，下载后即可运行，适合快速体验或只需要单个程序文件的用户。
- **`process-watchdog-2.0.0-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证、字体及运行所需资源，适合完整解压后长期使用或手动部署。
- **`process-watchdog-2.0.0-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试、文档和字体资源，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。

GitHub Release 页面只提供以上三个用户下载。SBOM、`SHA256SUMS.txt`、工具链快照、
解压目录和其他构建记录保存在本次 GitHub Actions 的完整构建产物中；三个下载的
SHA-256 同时记录在 GitHub Release API 的附件摘要中。
