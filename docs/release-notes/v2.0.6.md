# 🎉 进程守护小助手 v2.0.6

## ⚠️ 重要说明

- **发行附件变更**：从 v2.0.6 起不再提供独立 EXE；升级时必须改用完整便携版或源码版。
- **字体加载方式变更**：程序包不再内含或私有加载字体；需要原有首选字体显示效果时，必须下载可选字体包并安装到 Windows。

---

## 🚀 优化

- **精简程序版本**：发行流程仅构建完整便携版和完整源码版，删除独立 EXE 外层启动器、安装脚本及对应测试，避免同一程序维护三套交付路径。
- **系统字体与可选字体包**：运行时只按原有优先级选择 Windows 已安装字体；首选字体和回退字体改为独立下载，程序包及 SBOM 不再包含字体文件。
- **Everything 获取说明**：所有安装、配置和发行文档统一链接官方最新版，并明确 Everything 本体负责索引和后台服务，随包 DLL 仅负责 IPC 通信。
- **发布链路收敛**：构建、可复现性检查、附件清单、下载后验收和 GitHub Release 工作流统一验证两个程序版本及可选字体包，移除失效的独立 EXE 分支。

---

## 🐛 修复

- **主列表焦点清理**：点击主窗口空白表面或列表空白区域后会清除 ListView 的焦点和焦点项，避免已选守护对象继续保留键盘操作焦点。

---

## 📦 发布物说明

- **`process-watchdog-2.0.6-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **`process-watchdog-2.0.6-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.0.6-fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **Everything（官方最新版：https://www.voidtools.com/downloads/）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
