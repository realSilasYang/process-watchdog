# 🎉 进程守护小助手 v2.0.4

## ✨ 新增

- **主列表键盘控制**：主列表持有焦点时可按空格键暂停或恢复选中的守护对象；支持多选并逐项反转混合状态，长按产生的重复按键不会导致状态来回切换。

---

## 🚀 优化

- **守护对象术语**：界面、日志、配置注释和十三种语言文档统一使用符合功能语义的“守护对象”表达，减少“应用程序”“监控项”或“项目”在不同位置指代不一致的问题。
- **品牌与界面概览**：更新高清透明 Logo 和应用程序 ICO，并同步用于 README、程序窗口、托盘、任务栏和发行包；README 界面概览同时替换为当前主窗口画面。
- **发行说明结构**：历史及未来发行说明不再混入自动化验证清单，版本变化与三种下载方式保持清晰分区，完整验证证据继续保存在项目记录和 Actions 日志中。
- **发布预检稳定性**：新增本机一键发布预检入口，自动准备经上游摘要校验的便携 PowerShell 7、刷新构建工具并串联完整门禁；发行包字体校验直接读取 OpenType 元数据，不再受 PowerShell、.NET 或系统界面语言返回的本地化族名影响。

---

## 🐛 修复

- **日志路径操作对齐**：日志设置页的“浏览”按钮与上方路径输入框左侧对齐，避免操作入口偏离对应字段。

---

## 📦 发布物说明

- **`process-watchdog-2.0.4-windows-x64.exe`（独立可执行版）**：无需安装 AutoHotkey，下载后即可运行，适合快速体验或只需要单个程序文件的用户。
- **`process-watchdog-2.0.4-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证、字体及运行所需资源，适合完整解压后长期使用或手动部署。
- **`process-watchdog-2.0.4-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试、文档和字体资源，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
