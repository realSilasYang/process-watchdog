# 🎉 进程守护小助手 v2.0.12

## 🚀 优化

- **浅色主题完整适配**：针对窗口、输入框、列表状态、状态栏及语义图标逐项补充浅色配色，仅调整浅色背景下对比不足或与背景冲突的内容；原有深色调色板、图标原始像素和二维码资源保持不变。
- **主题切换显示更可靠**：主题相关图标使用独立缓存身份并在切换后及时刷新，避免沿用旧主题颜色；状态与操作图标在浅色界面下采用含义明确且清晰可辨的配色。
- **浅色悬停预览更易读**：悬停提示在浅色模式下使用浅灰蓝背景、近黑色 10 号界面字体、舒适内边距和最长 420 DIP 的自动换行，并保持延迟显示、鼠标穿透和 Windows 11 系统圆角；深色模式继续沿用原有表现。
- **打赏窗口更紧凑**：取消分隔线及附近多余空白，缩小窗口宽度，并为浅色模式提供专用二维码图片；提示文案同步更新至全部 13 种界面语言。

---

## 🐛 修复

- **主题切换后局部颜色不再滞留**：修复部分窗口按钮、状态栏和列表图标在深浅主题切换后未立即应用当前主题颜色的问题。
- **浅色界面文字与控件对比恢复正常**：修复部分只读文本、装饰背景和悬停预览在浅色背景下对比不足或视觉冲突的问题，同时不改变原有深色模式样式。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-2.0.12-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-2.0.12-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。
