# 🎉 进程守护小助手 v2.0.1

## 🚀 优化

- 按实际可见字形而非字体行框计算视觉中心，使 Lucide 图标、按钮文字、主列表状态图标和底部状态栏文字在 100% 与 300% DPI 下保持一致的垂直重心。
- 设置页首次构建和切换选项卡时在一次重绘事务内完成控件创建、显隐与标签状态更新，减少文字和页面内容先后刷新的闪烁观感。
- README 的全部十三种语言版本统一使用最新主窗口截图作为唯一界面概览，并删除不再使用的浅色旧图和双图主题切换结构。
- 更新日志和 GitHub Release 统一采用可扫描的 Emoji 标题与分类结构，逐项说明每种发布物的内容、运行要求和适用场景；历史版本说明也按其真实附件重新整理。

---

## 🐛 修复

- 修复字体热切换、状态 SVG 或管理员角标加载异常时主 ListView 图像列表可能解绑，导致部分或全部应用图标消失的问题；单个增强图标失败不再影响基础应用图标。
- 修复只指定状态图标纵向偏移时，空横坐标被当成无效整数或图标退到单元格左上角，导致状态图标创建失败、偏移或视觉尺寸异常的问题。
- 统一 Windows PowerShell 5.1 与 PowerShell 7 的 UTF-8、JSON、编译路径和 ZIP 字节；CI 的两轮发行构建现在强制跨两个宿主比较。
- Actions 完整构建产物显式保留隐藏目录，避免解压后的 `.github` 社区文件被上传步骤默认过滤。
- 发布门禁现在强制保留 Emoji 标题，并逐项核对三个公开发布物的文件名、版本定位、包含内容、运行要求和适用场景。

---

## 📦 发布物说明

- **`process-watchdog-2.0.1-windows-x64.exe`（独立可执行版）**：无需安装 AutoHotkey，下载后即可运行，适合快速体验或只需要单个程序文件的用户。
- **`process-watchdog-2.0.1-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证、字体及运行所需资源，适合完整解压后长期使用或手动部署。
- **`process-watchdog-2.0.1-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试、文档和字体资源，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。

GitHub Release 页面只提供以上三个用户下载。SBOM、`SHA256SUMS.txt`、工具链快照、
解压目录和其他构建记录保存在本次 GitHub Actions 的完整构建产物中；三个下载的
SHA-256 同时记录在 GitHub Release API 的附件摘要中。
