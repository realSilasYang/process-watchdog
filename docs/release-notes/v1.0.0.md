# 🎉 进程守护小助手 v1.0.0

## ⚠️ 重要说明

- 本版本没有自动更新功能。升级到 `v2.0.0` 或更高版本时，必须先退出旧实例，下载新版完整便携 ZIP 并完整解压，再迁移个人配置；不要只覆盖单个 EXE。

---

## ✨ 新增

- 支持守护进程、脚本和快捷方式，并通过基于证据的三态探活、共享调度与自动恢复维持目标运行。
- 提供软件升级保护、深色 GUI、自定义名称与图标、原子配置持久化、撤销与重做、日志及系统集成。
- 提供本地诊断包、Windows 持续集成、资源压力测试、可复现构建、发行校验和 SPDX SBOM。
- 提供快速开始、安装升级、配置、诊断、故障排查、兼容性及贡献文档。

---

## 🚀 优化

- 将本机运行配置与仓库示例配置分离，避免用户配置进入源码或发行内容。
- 将核心守护、检查、执行、配置、维护、诊断和 GUI 生命周期职责迁移到独立模块。
- 将主窗口图标、按钮交互、运行时适配、守护对象命令、状态日志和系统集成迁出根入口。

---

## 🐛 修复

- 修复按钮渲染器在 GDI+ 初始化、退出和重载期间的资源生命周期问题。
- 修复运行日志“导出诊断包”按钮的悬浮状态及点击回调注册顺序。
- 修复后台文件扫描的目录边界判断，以及临时文件被瞬时占用时的处理。

---

## 📦 发布物说明

- **`process-watchdog-1.0.0-windows-x64.zip`（完整 Windows x64 包）**：包含编译后的 `进程守护小助手.exe`、说明文档、许可证、状态图标及运行所需依赖；完整解压后即可运行，无需另行安装 AutoHotkey。
- **`process-watchdog-1.0.0-windows-x64.spdx.json`（SPDX 软件物料清单）**：记录应用、内嵌 AutoHotkey 运行时及第三方组件的版本、许可证和来源，供审阅与供应链核验；它不是可运行程序。
- **`SHA256SUMS.txt`（SHA-256 校验清单）**：记录 Windows ZIP 与 SPDX 文件的校验值，用于确认下载内容完整且未在传输过程中损坏；它不是可运行程序。
