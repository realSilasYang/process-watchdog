# 安装、升级与卸载

## 发行包

下载与系统架构匹配的 Windows x64 ZIP，核对同一 Release 中
`SHA256SUMS.txt`，然后完整解压。EXE、`assets/` 和 `third_party/` 必须保持
相对位置，不能只复制 EXE。

发行包已经包含运行所需的 AutoHotkey 运行时，不要求用户安装 AutoHotkey。
源码开发才需要 AutoHotkey v2 x64。

## 系统集成

打开“小助手设置”的“系统集成”页，可以创建桌面与开始菜单快捷方式，或创建
最高权限的登录自启计划任务。取消开机自启会删除由本程序创建且身份匹配的任务。

## 升级

1. 退出旧版本，或确认托盘中已经没有旧实例。
2. 备份旧目录中的 `watchdog.ini` 和未完成升级会话文件。
3. 将新发行包解压到新目录，复制原 `watchdog.ini` 后启动。
4. 查看 Release 说明中的配置格式变化和迁移要求。
5. 确认列表顺序、管理员设置、升级保护和自定义图标正常。

发行包永远不包含 `watchdog.ini`，覆盖程序文件不会主动覆盖个人配置。当前版本
只接受 README 所述的九字段监控项格式；无法解析的记录会进入 `[Recovery]`，
不会静默删除。

## 卸载

先在系统集成页取消开机自启，再退出程序并删除解压目录。桌面和开始菜单中由
用户创建的快捷方式可直接删除；程序不在注册表保存守护列表。
