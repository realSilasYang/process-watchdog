# 本地诊断包

**简体中文** | [English](en/diagnostics.md)

打开“运行日志”，点击“导出诊断包”，选择保存目录。程序会在系统临时目录收集
内容、压缩为 ZIP，再删除临时目录；不会自动上传。

诊断包包含：

- 应用版本、Windows 和 AutoHotkey 版本、DPI、GDI／USER 句柄计数。
- 守护对象总数、启用与暂停数量、守护阶段和升级阶段汇总。
- 调度队列、配置警告、恢复记录和日志数量。
- 当前日志窗口内容。
- 依赖锁定清单及 resvg、Everything 版本说明。

诊断包不复制完整 `watchdog.ini`，状态汇总不列出每个目标路径；但运行日志本身
可能包含路径和参数。公开提交前应先检查 `runtime-log.txt`。
