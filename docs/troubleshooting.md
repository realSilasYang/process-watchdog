# 故障排查

**简体中文** | [English](en/troubleshooting.md)

## 明明在运行却显示疑似停止

先打开运行日志，确认目标是 EXE、脚本还是快捷方式。快捷方式应查看日志中的
真实目标；脚本需要等待后台命令行快照。不要在“等待检查”期间手动重复启动。

若快捷方式来自 Windows Installer，目标可能位于版本化目录。重新添加快捷方式
可刷新真实目标；如果仍有多个同分候选，应在目标设置中明确实际主程序。

## 权限不符

已经运行的目标若没有满足“以管理员身份运行”设置，会显示权限不符。使用主界面
右键菜单“结束运行”停止目标并暂停守护，再恢复守护；小助手会按当前配置提权启动目标。

## 重新加载失败

重新加载会先启动独立解析验证；验证失败时旧实例继续运行。查看日志中的具体
脚本位置，执行以下命令获取完整错误：

```powershell
AutoHotkey64.exe /ErrorStdOut ".\进程守护小助手.ahk" --startup-validation
```

## 界面卡顿或资源持续增长

先关闭搜索、批量导入和日志窗口，观察是否恢复。随后在日志窗口导出诊断包，
并记录 Windows 版本、缩放比例、显示器数量和能稳定触发问题的操作顺序。

开发环境可以运行：

```powershell
.\tests\run-gui-tests.ps1 -SoakSeconds 300
```
