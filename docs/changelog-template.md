# 📝 中文更新日志模板

**简体中文** | [English](en/changelog-template.md)

新增版本时，把下面的版本块复制到根目录 `CHANGELOG.md` 的“未发布”内容下方，
再把已经发布的条目移入该版本。发布物说明必须保留；其余只保留本次实际包含的分类。
模板默认不生成“重要说明”，只有存在破坏性变化或用户必须执行的升级操作时才手动加入。

```markdown
## 🎉 版本 [X.Y.Z] - YYYY-MM-DD

### 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供首选字体和回退字体，需先安装到 Windows；它不是程序运行必需。
- **`process-watchdog-X.Y.Z-source.zip`（完整源码版）**：包含 AHK 源码、模块、测试和文档，不含字体，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`process-watchdog-X.Y.Z-windows-x64.zip`（完整便携版，推荐）**：包含 EXE、说明文档、许可证和运行所需资源，不含字体；无需安装 AutoHotkey，适合完整解压后长期使用。
- **Everything（[官方最新版](https://www.voidtools.com/downloads/)）**：为程序搜索提供索引和后台服务；随包 `Everything64.dll` 只是 IPC 客户端，不能替代 Everything 本体。

---

### ✨ 新增

- **功能名称**：说明新增了什么、适用于什么场景，以及用户可以获得什么。

---

### 🚀 优化

- **功能名称**：说明原有体验或行为如何改变，以及用户能够观察到的具体结果。

---

### 🐛 修复

- **问题名称**：说明原先会出现什么问题，以及修复后的正确行为。

---

### 🔒 安全

- **问题名称**：只在安全修复已经可以公开时保留，说明受影响版本、修复版本和用户
  是否需要立即操作；不要披露可直接利用的细节。
```

## 📐 编写规则

- 文档标题固定使用 `📋 更新日志`，版本标题固定使用
  `🎉 版本 [X.Y.Z] - YYYY-MM-DD`。版本号必须与 `VERSION`、主脚本
  Ahk2Exe 文件版本和 Git 标签一致；构建工具依赖该格式生成 SBOM 时间戳。
- 每个正式版本必须包含 `📦 发布物说明`，逐项给出三个准确文件名、版本定位、包含
  内容、AutoHotkey 要求和适用场景；三个附件必须按 GitHub 的固定展示顺序列为
  `fonts.zip`、源码 ZIP、便携 ZIP，Everything 使用显式 Markdown 链接并排在其后。
  发布门禁会核对这些信息，不能只写“见附件”。
- `⚠️ 重要说明` 是可选的警告章节，默认不生成。只有现有数据或配置不兼容、可能
  丢失数据、最低环境或权限发生破坏性变化、原有默认行为带来升级风险，或者用户必须
  在升级前后执行迁移、备份、替换等操作时才加入。
- 不得把“配置保持兼容”“可直接升级”“推荐下载便携包”、发行物选择、功能简介、
  一般使用建议或验证范围写进 `⚠️ 重要说明`。若存在该章节，每项必须写清受影响对象、
  具体风险和必要操作，并置于常规分类之前；没有合格事项时连标题一起删除。
- 常规分类固定使用 `✨ 新增`、`🚀 优化`、`🐛 修复`；没有内容的分类直接删除。
  `🔒 安全` 仅在协调披露后使用。
- 更新日志和 Release Notes 均不得包含“✅ 验证范围”章节，也不得罗列测试数量、
  浸泡循环、构建哈希或尚未完成的人工矩阵。验证结果统一保存在专门的验证证据、
  CI／Release Actions 日志和完整构建产物中。
- 每项先用粗体短语概括功能或问题，再用完整中文说明用户可见变化、适用范围和收益。
- 合并同一功能的零散提交，不直接罗列提交标题、文件名、内部类名、变量名或纯重构
  过程。内部变化只有在影响可靠性、性能、兼容性或维护边界时才写入。
- 配置格式、默认值、权限、系统集成和最低环境发生变化时，必须说明旧
  配置如何处理、是否需要备份，以及失败后怎样恢复。
- GUI、DPI、暗色模式或多显示器变化只描述实际完成的范围；未经物理设备验证的组合
  必须在 Release 说明和人工回归矩阵中标记，不能写成已经全面支持。
- 发布版本后更新文件末尾的比较链接：`[未发布]` 指向最新标签到 `HEAD`，版本链接
  指向对应 GitHub Release。

## 发布前示例

## 🚧 [未发布]

### 🚀 优化

- **问题反馈流程**：缺陷表单现在收集 Windows、显示缩放、目标类型和运行上下文，
