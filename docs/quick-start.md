# 常见使用场景

## 守护普通桌面程序

点击“添加”并选择主程序 EXE。小助手会优先按完整镜像路径识别进程；如果目标
已经运行，会接管其 PID 身份，不会重复启动。

## 守护快捷方式

直接添加 LNK。小助手保留快捷方式自身的启动参数，同时解析真实目标用于探活。
MSI 快捷方式或目标路径会随版本变化的软件，会结合安装目录候选和当前进程
证据选择主程序。

## 守护脚本和命令行工具

支持 AHK、Python、JavaScript、PowerShell、BAT 和 CMD。脚本目标需要命令行
证据；证据快照尚未完成时状态为“等待检查”，不会把未知状态误判为停止。

## 需要管理员权限的程序

在项目设置中开启“以管理员身份运行”。如果已经运行的目标权限不符，主界面
会提示；通过右键重新启动时，小助手会按该设置提权启动。

## 会自动升级的软件

软件升级保护默认关闭。确认安装目录后手动开启；小助手会结合更新进程、父子
关系、命令行根目录引用和文件变化进入升级状态，在目标文件重新稳定后恢复守护。
如果软件提供明确的“检查更新”入口，可以在升级保护页面开始和结束显式维护。
