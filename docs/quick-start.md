# 常见使用场景

**简体中文** | [English](en/quick-start.md)

## 守护普通桌面程序

点击“添加”并选择主程序 EXE。小助手会优先按完整镜像路径识别进程；如果目标
已经运行，会接管其 PID 身份，不会重复启动。

## 守护快捷方式

直接添加 LNK。小助手保留快捷方式自身的启动参数，同时解析真实目标用于探活。
MSI 快捷方式或目标路径会随版本变化的软件，会结合安装目录候选和当前进程
证据选择主程序。

## 目标文件被更名或移动

直接添加的 EXE 或脚本本身被更名、上级目录被改名，或跨目录、跨磁盘移动后，
小助手会先按兼容扩展名和精确文件大小筛选候选，再以完整 SHA-256 内容哈希确认
文件内容没有变化。内容基线会随配置保存，因此移动发生在小助手关闭期间也能识别；
文件名、Windows 文件 ID 和目录监听都不参与迁移判断。

找到候选后，小助手会冻结该守护对象尚未执行的重启任务并显示原路径、新路径和识别
依据。选择“更新守护路径”后，名称、图标、参数、环境变量、运行时和升级保护设置
都会保留，修改也可通过撤销恢复；选择“忽略”则继续按原路径报告目标缺失。升级
保护正在判断或执行升级时，常规内容迁移不会显示更名确认，避免把更新器留下的备份
文件当作新目标；版本目录升级是受限例外，规则见下方“会自动升级的软件”。

扫描在独立工作进程中执行，不会阻塞守护和界面。若发现多个内容完全相同的副本，
或任一搜索位置未能完整扫描，小助手不会猜测目标，而会保留原路径并稍后重试。

## 守护脚本和命令行工具

支持 AHK、Python、JavaScript、PowerShell、BAT、CMD、Ruby、Perl、PHP、Lua、
JAR 和 Shell 等目标。脚本目标需要命令行证据；证据快照尚未完成时状态为“等待
检查”，不会把未知状态误判为停止。

右键直接脚本并打开“进程识别与启动设置”，可以配置通用启动环境：

| 设置 | 作用 | 示例 |
| --- | --- | --- |
| 启动程序或解释器 | 固定实际执行脚本的运行时 | 虚拟环境的 `python.exe`、`AutoHotkey64.exe`、`pwsh.exe`、`node.exe`、`java.exe` |
| 启动程序参数 | 放在目标路径之前，属于运行时本身 | PowerShell 的 `-NoProfile -File`、Java 的 `-jar`、AutoHotkey 的 `/ErrorStdOut` |
| 工作目录 | 为相对文件、模块和配置提供 CWD | 项目根目录或脚本所在目录 |
| 目标参数 | 放在目标路径之后，传给脚本或任务 | `--config production.json` |
| 环境变量 | 逐行临时覆盖启动环境 | `NODE_ENV=production`、`PATH=C:\Tools;%PATH%` |

实际命令顺序是 `"启动程序" 启动程序参数 "目标路径" 目标参数`。所有字段只在
小助手下次启动目标时生效，不会重启或修改已经运行的进程。留空启动程序即可沿用
目标类型的默认方式。快捷方式和普通 EXE 不显示运行时字段：LNK 必须保留安装器、
工作目录和内置参数等启动语义，EXE 则直接运行；如需复杂包装流程，可创建明确的
启动脚本或快捷方式后再加入守护。

## 使用 Everything 搜索程序

小助手附带的 `Everything64.dll` 是 Everything SDK 的 IPC 客户端，只负责向已经
运行的 Everything 后台实例提交查询；它不包含索引器，不能单独扫描磁盘或替代
Everything 完整版。打开搜索窗口时，如果没有可用后台实例，小助手会在注册表、
常见安装目录、`PATH`、桌面和开始菜单快捷方式中进行有界查找；找到
`Everything.exe` 后使用官方 `-startup` 参数静默启动，再继续搜索。

如果本机没有 Everything，搜索窗口会提供可点击的官方最新版下载地址。小助手不会
退回主线程全盘扫描，也不设置应用层结果上限；文件夹批量导入不依赖 Everything。

## 需要管理员权限的程序

在守护对象设置中开启“以管理员身份运行”。如果已经运行的目标权限不符，主界面
会提示。需要按新设置重新启动目标时，先用右键菜单“结束运行”，再恢复守护；
小助手会在下一次启动时按该设置提权。

## 会自动升级的软件

软件升级保护默认关闭。确认安装目录后手动开启；小助手会结合更新进程、父子
关系、命令行根目录引用和文件变化进入升级状态，在目标文件重新稳定后恢复守护。
如果软件提供明确的“检查更新”入口，可以在升级保护页面开始和结束显式维护。

更新程序学习只在一次真实升级改变目标文件并成功完成后发生，而且只接受安装足迹内
具有完整路径的专属程序，以“完整路径 + 安装根”保存。全局 `msiexec`／`winget`、
临时目录程序、只有进程名的候选和失败升级不会留下永久记录；升级未完成时会话只临时
保存已经确认的更新进程和待学习特征，以便小助手重启后继续判断。

如果目标位于 `2.0.10`、`v2.0.11` 等版本目录，升级已确认且目标文件发生变化后，
小助手会检查同一父目录中的其他版本目录。只有唯一同名新入口时才显示迁移确认，
并持续校验候选 SHA-256；多个候选、重复副本或扫描不完整时不会猜测。升级后进程
镜像路径暂时不可访问时，也必须同时满足同名进程唯一、创建身份与升级前一致或属于
近期启动，才会确认目标已经恢复。
