# 兼容性与已知限制

## 受支持环境

| 项目 | 当前基准 |
| --- | --- |
| 操作系统 | Windows 10 x64、Windows 11 x64 |
| 源码运行时 | AutoHotkey v2.0.26 x64 |
| 发行包 | AutoHotkey v2.0.26 与 Ahk2Exe 1.1.37.02a2 |
| 显示缩放 | 100%、125%、150%、175%、200% 手工矩阵 |
| 文件系统 | 本机 NTFS；程序目录需要能够写入配置和维护会话 |

CI 在 Windows Server 2022 上执行启动、核心、真实 GUI 和编译版验证。物理多显示器、
跨显示器 DPI 切换和高对比度主题仍需要人工检查。

## 已知限制

- 只支持 x64，不提供 Windows 7、32 位或非 Windows 平台版本。
- GIF 和 ANI 自定义图标在 ListView 中显示静态代表帧，不播放动画。
- WebP 依赖系统 WIC 编解码器或 Shell 缩略图处理器。
- 自绘暗色控件依赖 Windows 10／11 的实际主题实现，不同系统构建可能存在细微差异。
- 当前配置只接受最新九字段格式，跨破坏性版本升级需要 Release 提供的迁移步骤。
- 本项目保留原生 ListView 滚动，不使用已经撤销的 GDI 截图覆盖式平滑滚动。
