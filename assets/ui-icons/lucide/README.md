# Lucide 界面图标

本目录包含从 [Lucide Icons](https://github.com/lucide-icons/lucide) `lucide-static 1.27.0` 选取的界面图标。为保证小尺寸按钮在深浅主题下均有清晰语义和足够对比度，本项目为图标设置了固定语义配色，并移除了不参与渲染的尺寸和类名属性。管理员徽标由 Windows Shell 在运行时提供，不属于本目录，其实现说明见上级目录。状态信息使用独立的稳定语义键：只有运行、暂停、升级、恢复等含义确实相同的项目才与底部统计栏复用图标；初始化、等待观察、倒计时、启动、验证、文件等待等细分状态各自使用匹配图形和互不重复的颜色。常见状态优先使用直观的蓝、绿、黄、橙、红，低频状态再使用青、紫、玫红、青绿和中性色。同一上游几何需要区分不同阶段或按钮背景时，仅建立不同语义配色的资源变体，路径保持上游设计。功能按钮在语义一致且对比度合适时直接复用同一资源；确定、保存、取消等表单提交按钮保持纯文字，不附加装饰图形。

运行时由项目现有的 resvg 管线将 SVG 一次性转换为透明预乘 BGRA 像素，后续重绘不再读取或解析文件。
