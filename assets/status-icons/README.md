# 状态图标资源

本目录包含主列表九种状态使用的 64×64 重绘版 SVG。所有图形均针对
20～48 像素的实际 ListView 显示尺寸重新绘制，不再直接复用上游复杂路径：
圆形使用精确 `<circle>`，方形使用精确圆角矩形，斜边标志采用对称坐标；
白色语义符号与彩色容器之间保留固定安全区。运行时仅加载这些资源，不会
动态计算或拼接图标几何。

| 项目文件 | 语义 | 几何设计 |
| --- | --- | --- |
| `running.svg` | 正常运行 | 圆角方形＋粗线勾 |
| `paused.svg` | 已暂停 | 正圆＋等宽暂停条 |
| `warning.svg` | 警告 | 对称八边形＋感叹号 |
| `suspected-stop.svg` | 疑似停止 | 圆角三角形＋感叹号 |
| `error.svg` | 明确错误 | 正圆＋交叉线 |
| `pending.svg` | 等待检查 | 正圆＋时钟指针 |
| `countdown.svg` | 重试倒计时 | 正圆＋实心沙漏 |
| `updating.svg` | 更新中 | 正圆＋双向循环箭头 |
| `idle.svg` | 空闲／低频 | 正圆＋三点 |

## 配色语义

| 状态 | 颜色 | 语义 |
| --- | --- | --- |
| 运行 | `#2FBF71` | 翠绿表示健康、可用 |
| 暂停 | `#C9902E` | 低饱和琥珀表示主动停驻 |
| 警告 | `#E5B73B` | 金黄表示需要关注 |
| 疑似停止 | `#F07A3E` | 橙色表示风险正在升级 |
| 错误 | `#DC5666` | 绯红表示明确失败 |
| 等待检查 | `#3D8FE3` | 天蓝表示信息性等待 |
| 重试倒计时 | `#20A7B9` | 青色表示计时过程 |
| 更新中 | `#8D6AD8` | 紫色表示系统维护过程 |
| 空闲／低频 | `#718096` | 蓝灰表示非活跃状态 |

图标的状态语义参考通用交通安全标志与圆角界面图标规范，几何路径为本项目
重新绘制。SVG 栅格化仍由项目随附的 resvg 完成，其许可证位于
`third_party/resvg/LICENSE-APACHE`。
